# Notices

The look of this crate (the centred rules, the nested numbered tabs, the
accent-lit current tab, the "key label · key label" hints and the "Yes ▸ No"
confirm bar) is in the style of HEY's terminal UI by 37signals
([basecamp/hey-cli](https://github.com/basecamp/hey-cli)). No code or text is
copied from it.
